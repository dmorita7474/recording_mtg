# プロジェクト定義

## 日時
2026-03-07

## 指示内容
このプロジェクトではClaude Codeを使ってバイブコーディングでアプリケーション開発を行います。
後で生成過程を振り返り、指示文を改善するために、必ずユーザーの指示を.claude/instructions/配下に残すようにしてください。

## ルール
- ユーザーの指示は必ず `.claude/instructions/` 配下にファイルとして保存する
- ファイル名は `{連番}_{概要}.md` の形式とする（例: `001_project_definition.md`）
- 指示内容、日時、および補足情報を記録する
